Getting Started
Deploy in 4 Steps
01
📋
Open Remix IDE
Go to remix.ethereum.org, create VehicleRegistry.sol and paste the contract code
02
🦊
Deploy via MetaMask
Select Injected Provider — MetaMask on Sepolia Testnet, click Deploy and confirm the transaction
03
⚙️
Update CONTRACT_ADDRESS
Copy the deployed address → paste into app.js line 13 as CONTRACT_ADDRESS
04
🚀
Launch & Use
Refresh localhost:3000, connect MetaMask → register vehicles, transfer ownership and track history!
